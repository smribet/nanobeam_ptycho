# Nanobeam Ptychography paper

Data and analysis code for "Real-space overlap is not enough: ambiguity in nanobeam iterative ptychography" manuscript by S.M. Ribet, M. Danaie, W.P.M. de Kleijne, A.R.C. McCray, F. Allars, C.S. Allen, C. Ophus, and G. Varnavides.

## Contents

| directory | what's in it |
|---|---|
| [`experimental-results/`](experimental-results/) | experimental datasets and their analysis code |
| [`simulated-results/`](simulated-results/) | multislice simulations, reconstruction sweeps, and the code that makes the figures |

Each directory carries its own README with the details.
